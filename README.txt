HOW TO OPEN THE WEBSITE

Fastest method:
1. Unzip the downloaded folder.
2. Open the folder named easy-site.
3. Double-click index.html.
4. The website will open in your default browser.

You do not need to install anything.

HOW TO EDIT IT

- Open index.html in any text editor to change the text and links.
- Open style.css to change colors, spacing, and font sizes.
- Keep index.html and style.css in the same folder.

Optional local server (if you have Python installed):
1. Open a terminal in the easy-site folder.
2. Run: python3 -m http.server 8000
3. Open: http://localhost:8000
4. Stop the server with Ctrl+C.
